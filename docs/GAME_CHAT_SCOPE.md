# Игровой чат и доступ к подпискам

При запуске бот разрешает Telegram username `@airchatton` через `getChat` и привязывает игровую группу к числовому ID. Если имя недоступно, указывает не на группу или заданный `MAIN_CHAT_ID` не совпадает с полученным ID, запуск прекращается: не подставляйте ID другого чата. Старый `ALLOWED_CHATS` в процессе заменяется единственным ID. Если у бота нет доступа к группе или Telegram недоступен при старте, его нужно восстановить и перезапустить сервис.

Сообщения, реакции, callback и изменения членства обрабатываются только в этой группе и в личке. Проверки `getChat`/`getChatMember` не ограничиваются: бот может быть администратором других каналов и проверять подписки в заданиях. Личные сообщения, покупка, квитанции, `/task_add` и управление заданиями остаются доступны. Финансовые квитанции обрабатываются до фильтра группы; защита исходящих действий не позволяет ответить в чужую группу. Исторические фоновые Banzai/босс в других группах не возобновляются и не удаляются автоматически; нужна проверка оператором.

Inline-запрос не содержит достоверного ID чата назначения, поэтому inline-игры/чеки отключены даже в разрешённой группе; кнопки старых inline-сообщений тоже недоступны. Реферальной ссылкой по-прежнему можно поделиться. Обычные игры и `/dojo` в @airchatton сохраняются.

Кампания комментариев допустима только если обсуждение привязано к @airchatton. При явно заданном другом `DISCUSSION_CHAT_ID` она отключается при старте; при автоматическом определении неверной группы запуск завершается ошибкой. Каналы для заданий от этого не зависят. Перед деплоем проверить MAIN_CHAT_ID, права администратора, настройки кампании и приостановленные старые игры. Не менять данные без отдельного решения.
