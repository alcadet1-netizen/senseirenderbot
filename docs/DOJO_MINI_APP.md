# Стенка на Стенку — запуск в Telegram

## Что подключено

- Существующий HTTP-процесс бота отдаёт корневой `index.html` по `/miniapp/dojo` и `/miniapp/dojo/`. Дополнительный сервер в production не нужен; `/` и `/health` не изменены.
- `/dojo` в личном чате присылает inline-кнопку с `WebAppInfo`. В группе команда просит перейти в личку (Web App inline-кнопки предназначены для личного чата).
- Размещённая версия загружает официальный Telegram WebApp SDK: ready/expand, цвета оболочки, стабильная высота, haptic и BackButton (закрывает меню, затем приложение).
- Офлайн `file://` не загружает SDK. При недоступности SDK игра продолжает работать как обычная страница.
- Это локальный прототип: сохранение на устройстве, нет авторизации на сервере, переводов Coin, наград, NFT или синхронизации между устройствами. Непроверенные Telegram initData не используются как основание для серверных действий.

## Проверить в настоящем Telegram

1. Слить изменения и выполнить обычный деплой бота. В Docker `COPY . .` уже включает `index.html`.
2. На Render используется встроенная `RENDER_EXTERNAL_URL` (публичный HTTPS origin). Код добавляет `/miniapp/dojo`. Дополнительные переменные не нужны.
3. Для другого хостинга задать **полный HTTPS URL**, например `DOJO_APP_URL=https://<ваш-домен>/miniapp/dojo`, и перезапустить сервис. Эта настройка имеет приоритет над Render. Отдельная старая настройка `MINI_APP_URL` не изменяется.
4. Проверить публичный URL: он должен возвращать игру, а `/health` — `OK`. Если перед сервером есть reverse proxy, он не должен добавлять запрет встраивания `X-Frame-Options: DENY/SAMEORIGIN` к странице Mini App.
5. Открыть личный чат с ботом → `/dojo` → «🎮 Играть». Настройка BotFather для этой inline-кнопки не требуется.
6. Проверить призыв, апгрейд, свайп ци, паузу в правилах, BackButton, сворачивание/возврат и сохранение при повторном открытии. Отдельно проверить Android/iOS/Desktop.

Необязательно: через @BotFather `/setmenubutton` установить кнопку «🎮 Играть» с тем же HTTPS URL. Код не перезаписывает существующую кнопку меню бота.

Если команда отсутствует, проверьте, что задеплоен новый коммит. Если ответ сообщает о непубликованной игре — отсутствует корректный DOJO_APP_URL/RENDER_EXTERNAL_URL. Не присылайте токен бота или initData в чат/логи.
