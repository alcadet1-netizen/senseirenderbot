## 🔍 Как проверить начисление монет и достижений:

1. **Запустите бота в групповом чате** (в личных сообщениях награды не начисляются – защита от спама)
2. **Отправьте несколько сообщений** и проверьте логи или команду `/профиль`:
   - Начисление ~`+9.00 монет, +10 XP` за сообщение (с учётом халвинга)
   - Каждые 300 сообщений: билет `🎫 Вы билет №XXXXXXXX!`
3. **Для достижений**: достичь порогов (например, 1.message, 100.messages, 1000.messages) и наблюдать за уведомлениями о разблокировке с наградами
4. **Для throttle**: быстро отправлять команды подряд – должно появляться предупреждение но команда всё равно выполнится

## 📝 Следующие шаги (по запросу):

Если вы хотите полностью соответствовать резервному боту, необходимо апгрейд функции `upgrade_katana` в `src/services/economy_service.py` использовать динамическую стоимость из `KATANA_UPGRADE_COST_TABLE` текущей длины ката, а не фиксированную `KATANA_UPGRADE_COST`.

Это можно сделать, добавив метод semelhный к тому, что есть в резервном боте:
```python
def _get_katana_upgrade_cost(self, katana_length: float) -> float:
    for max_length, cost in KATANA_UPGRADE_COST_TABLE:
        if katana_length < max_length:
            return cost
    return KATANA_UPGRADE_COST  # Fallback
```
И использовать его в функции `upgrade_katana` вместо прямого обращения к `KATANA_UPGRADE_COST`.
